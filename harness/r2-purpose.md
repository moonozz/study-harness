# R2 목적

## 실행마다 달라지는 입력

| 항목 | 조건 |
| --- | --- |
| 경쟁사 레퍼런스 | 1개 이상 |
| 대상 화면 | 2~3개 |
| 작업 범위 | 실행마다 지정 |

## 사용자와 승인자

| 역할 | 담당 |
| --- | --- |
| 주 사용자 | 나 |
| 검토자 | 나 |
| 사람 승인자 | 내부 관계자 |

## 고정 기준

- `docs/prd.md`
- `docs/design.md`
- `docs/story-service.md`
- `docs/story-work.md`
- 화면 크기: `390x844`
- 카테고리 수: 7개

## 완료 기준

레퍼런스 분석 결과, 화면 설계 문서, UI 키스크린 2~3개, 디자인 토큰과 컴포넌트, 가이드 검토 결과가 생성되고 필수 게이트가 모두 승인되며 미해결 가이드 위반이 0개이면 완료한다.

## 기계 판정값

| 판정 항목 | 통과 조건 |
| --- | --- |
| 레퍼런스 수 | `references >= 1` |
| UI 키스크린 수 | `2 <= key_screens <= 3` |
| 화면 크기 | `frame_width == 390 && frame_height == 844` |
| 필수 게이트 승인 | `required_gates_approved == true` |
| 미해결 가이드 위반 | `unresolved_violations == 0` |
