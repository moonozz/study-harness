# R8 검증과 리뷰

## 판정 스크립트

아래 명령으로 실행별 산출물과 상태를 검증한다.

```bash
python3 harness/scripts/validate.py --run runs/<run-id>
```

종료 코드는 아래와 같이 구분한다.

| 종료 코드 | 의미 |
| --- | --- |
| `0` | 모든 검증 통과 |
| `1` | 게이트 실패 |
| `2` | 규칙 또는 입력 형식 오류 |

## 필수 검증 시나리오

| # | 시나리오 | 기대 결과 |
| --- | --- | --- |
| 1 | 정상 입력으로 전체 파이프라인 실행 | 모든 단계 통과 |
| 2 | 레퍼런스가 0개인 상태로 분석 완료 시도 | 1단계 실패 |
| 3 | 레퍼런스 출처가 누락됨 | 1단계 실패 |
| 4 | 키스크린이 2개 미만이거나 3개 초과임 | 3단계 실패 |
| 5 | 키스크린 프레임이 `390x844`가 아님 | 3단계 실패 |
| 6 | 기존 7개 목록에 없는 카테고리를 사용함 | 위반이 발생한 단계 실패 |
| 7 | 확인되지 않은 설명이나 URL을 사실로 기록함 | 위반이 발생한 단계 실패 |
| 8 | 사람 승인 없이 4단계 진입을 시도함 | 실행 중단 및 `waiting_approval` 유지 |
| 9 | 최종 가이드 위반이 발견됨 | 4단계로 복귀 |
| 10 | 중단된 실행을 재개함 | 처음 발견된 `passed`가 아닌 단계부터 시작 |

아래 명령으로 필수 시나리오와 형식 오류·판정자 쓰기 시도 방어 테스트를 실행한다.

```bash
python3 -m unittest discover -s harness/tests -p 'test_*.py' -v
```

테스트에는 Codex 프로젝트 스킬, 훅 구성, 역할별 쓰기 범위, 오케스트레이터 상태 전이를 포함한다.

## 전체 통과 기준

아래 조건을 모두 만족해야 검증 완료로 판정한다.

- `failed_tests == 0`
- `gate_false_negatives == 0`
- `unexpected_stage_transitions == 0`
- `judge_write_attempts == 0`

## 최종 리뷰

검증 결과는 `harness/verification-report.md`에 시나리오별 결과와 남은 위험을 기록한다.

전체 라운드가 끝나면 `AGENTS.md` 초안을 사용자에게 먼저 보여준다. 사용자 승인 전에는 `AGENTS.md`를 생성하지 않는다.
