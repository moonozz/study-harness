# R3 파이프라인

## 단계별 입출력과 복귀 지점

| 단계 | 입력 | 출력 | 실패 시 복귀 |
| --- | --- | --- | --- |
| 1. 레퍼런스 분석 | 경쟁사 레퍼런스 1개 이상, 작업 범위 | 레퍼런스 수집본, 분석 결과, 서비스 반영 후보 | 1단계 재실행 |
| 2. 화면 설계 | 승인된 분석 결과, `docs/prd.md` | 화면 설계 문서 | 2단계로 복귀 |
| 3. 키스크린 제작 | 승인된 화면 설계, `docs/design.md` | `390x844` UI 키스크린 2~3개 | 3단계로 복귀 |
| 4. 디자인 제작 | 승인된 키스크린 | 디자인 토큰, 컴포넌트, 화면 디자인 | 4단계로 복귀 |
| 5. 가이드 검토 | 완성된 디자인, `docs/design.md` | 위반 항목과 판정 결과 | 위반 발견 시 4단계로 복귀 |

## 단계 진입 조건

1단계를 제외한 모든 단계는 아래 조건을 모두 만족할 때만 시작한다.

- `previous_output_exists == true`
- `previous_gate_passed == true`

## 파이프라인 순서

`레퍼런스 분석 -> 화면 설계 -> 키스크린 제작 -> 디자인 제작 -> 가이드 검토`
